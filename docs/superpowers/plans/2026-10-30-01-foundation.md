# Foundation Implementation Plan (Plan 1 of 6)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the empty Views template into a Compose + Hilt app on the latest toolchain, with the RN boilerplate's design tokens, a persisted System/Light/Dark theme, en/id language switching, type-safe navigation, and the styling showcase pages.

**Architecture:** Single `:app` module, packages `app/`, `core/…`, `feature/…` (spec §4). State lives in ViewModels exposing `StateFlow`; preferences in DataStore; Hilt wires singletons. Screens are split into a stateless `XxxScreen(state, callbacks)` (tested with Robolectric) and a thin `XxxRoute` that obtains the ViewModel via `hiltViewModel()`.

**Tech Stack:** AGP 9.4.0 (built-in Kotlin), Gradle 9.6.0, Kotlin 2.4.21, Compose (BOM) + Material 3, Navigation Compose (type-safe), Hilt + KSP, DataStore Preferences, AppCompat (per-app locales), core-splashscreen, kotlinx.serialization, JUnit4 + Robolectric + Compose UI test + kotlinx-coroutines-test + Turbine, ktlint.

**Spec:** `docs/superpowers/specs/2026-10-30-kotlin-android-starter-design.md`
**Reference source (behaviour & values):** `D:\RN\rn-expo-boilerplate`

- Must build and test on Windows with `gradlew.bat`. Proof command for every task: `./gradlew testDebugUnitTest ktlintCheck assembleDebug`.

## Review Focus

1. **Corrupted/unknown stored theme value** (e.g. `"PURPLE"` left by an older build) → app starts in `SYSTEM`, no crash. Test in Task 3.
2. **DataStore read fails (IOException)** → splash must not hang forever; theme falls back to `SYSTEM`. Test in Task 3.
3. **Device language not supported** (e.g. `ja-JP`) → UI in English, Settings shows English selected. Test in Task 4.
4. **Indonesian string with a missing/different format placeholder** → runtime crash on `stringResource(id, arg)`. Completeness test also compares placeholders. Test in Task 4.
5. **Large font scale (200%)** → Home entries still displayed (no fixed heights clipping text). Test in Task 5.
